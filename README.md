# One for All  

## Descrição breve  
Este projeto dá continuidade ao aprendizado iniciado no **All for One**, porém com maior complexidade. Aqui, desenvolvi habilidades na criação, leitura e popularização de tabelas, além de aplicar novos conceitos de bancos de dados, como relações 1:N e N:N. Também pratiquei a criação de consultas SQL mais avançadas.  

## Como rodar o projeto  
1. Clone o repositório:  
   ```bash
   git clone https://github.com/Gzuuu/mysql-one-for-all.git
   ```  
2. Navegue para a pasta do projeto:  
   ```bash
   cd one-for-all
   ```  
3. Instale as dependências:  
   ```bash
   npm install
   ```  
4. Caso deseje, execute os testes:  
   ```bash
   npm test
   ```  

> **Nota:** Assim como o **All for One**, este também é um projeto backend e não possui interface de usuário.  

## Tecnologias utilizadas  
- Docker Compose  
- MySQL Workbench  
- JavaScript  

## Principais aprendizados  
- Modelagem de dados mais avançada com relações 1:N e N:N.  
- Construção de consultas SQL sofisticadas para diversas necessidades.  
- Ferramentas adicionais como MySQL Workbench para visualização e gerenciamento.
